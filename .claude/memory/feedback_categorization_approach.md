RefSeeker должен оставаться универсальным. Закрытый список категорий (даже с "other" fallback) убивает универсальность — для "vintage typewriter" авиа-категории бессмысленны.

**Why:** Проект изначально задуман как универсальный сборщик референсов для любых запросов. Закрытый enum делает его узконаправленным и требует постоянного расширения под каждый новый тип запроса.

**How to apply:**
- GPT генерирует категории свободно, Python только санитизирует (lowercase, блокировка path traversal)
- Промпт содержит generic guidance (5-10 категорий, консистентность, конкретные имена), но не примеры из конкретной предметной области
- Без difflib-нормализации — он не отличает "wing" от "wind"
- Без двух проходов GPT — оверхед не оправдан для cosmetic-проблемы
