# RefSeeker — автоматический сбор референсных изображений

**RefSeeker** — Python-утилита для автоматического поиска и загрузки качественных референсных изображений через браузер с использованием ИИ.

## Возможности

- **Автоматический поиск** — агент на базе DeepSeek самостоятельно ищет изображения, навигирует по сайтам и собирает ссылки
- **Интеллектуальная фильтрация** — каждое изображение проверяется через GPT-4o mini на релевантность, качество и наличие водяных знаков
- **Прогрессивное сохранение** — изображения сохраняются сразу по мере нахождения, не дожидаясь обхода всех страниц
- **Авто-сортировка по категориям** — ИИ определяет, что изображено на фото (например, `cockpit`, `wing`, `engine`), и раскладывает по соответствующим подпапкам
- **Гибкая настройка сайтов** — белый и чёрный списки доменов через `config.json`
- **Улучшение запроса** — опционально ИИ расширяет поисковый запрос для лучших результатов

## Установка

### Требования

- Python 3.10+
- [Playwright](https://playwright.dev/) (Chromium)
- API-ключи OpenAI и DeepSeek

### Шаги

```bash
# 1. Клонировать репозиторий
git clone <url>
cd RefSeeker

# 2. Создать виртуальное окружение
python -m venv .venv

# 3. Активировать окружение
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Установить браузер Playwright
playwright install chromium

# 6. Настроить API-ключи
echo "OPENAI_API_KEY=sk-your-key-here" > .env
echo "DEEPSEEK_API_KEY=sk-your-deepseek-key-here" >> .env
```

## Настройка

### `.env`

```
OPENAI_API_KEY=sk-your-key-here
DEEPSEEK_API_KEY=sk-your-deepseek-key-here
```

### `config.json`

```json
{
    "whitelist": [
        "net-maquettes.com",
        "cybermodeler.com"
    ],
    "blacklist": [
        "pinterest.com",
        "instagram.com",
        "facebook.com",
        "reddit.com",
        "twitter.com",
        "x.com"
    ]
}
```

- **whitelist** — сайты, которые агент ищет в первую очередь (приоритетные)
- **blacklist** — сайты, которые агент строго избегает

## Использование

```bash
python main.py
```

1. Введите поисковый запрос (например, `A-20G Havoc`)
2. При желании улучшите запрос через DeepSeek (`y`/`n`)
3. Агент запускает браузер и начинает сбор
4. Изображения сохраняются в `./references/<query>/<category>/`

**Цель:** 10–30 качественных изображений на запрос.

## Как это работает

### Поток выполнения

```
Ввод запроса → Улучшить запрос? [y/n]
    → Агент (DeepSeek) открывает Google, ищет "запрос reference photos"
    → Переходит на найденные сайты
    → Собирает URL изображений со страницы
    → Немедленно скачивает (_download_candidates) и отправляет на верификацию
    → Изображения проходят проверку GPT-4o mini (разрешение, качество, водяные знаки)
    → Одобренные сохраняются в папку с категорией
    → Агент идёт на подстраницы (pic-1.htm, gallery/1 и т.д.)
    → Повторяет сбор и сохранение
    → Останавливается при достижении 10–30 изображений
```

### Ключевые компоненты

| Инструмент / функция | Описание |
|---|---|
| `get_page_image_urls` (controller) | Извлекает все `<img>` URL, скроллит страницу, запускает скачивание и верификацию |
| `extract_subpage_links` (controller) | Находит ссылки на подстраницы с изображениями |
| `_download_candidates` | Скачивает до 50 изображений асинхронно, проверяет разрешение (>300px), отфильтровывает битые |
| `_verify_and_save` | Отправляет батч в GPT-4o mini для верификации и категоризации, сохраняет одобренные |
| `_download_single` | Скачивает одно изображение через браузер (fetch + CDP, обход CORS) или Python fallback |

### Фильтрация изображений

Каждое изображение проходит три этапа проверки:

1. **Разрешение** — не менее 300×300 пикселей (проверяется до вызова GPT)
2. **Релевантность** — GPT-4o mini определяет, относится ли изображение к запросу
3. **Качество** — проверка на резкость, водяные знаки, текстовые наложения

Одобренные изображения получают категорию (например, `cockpit`, `wing`, `landing_gear`) и сохраняются в соответствующую подпапку.

## Зависимости

- `browser-use` — управление браузером через ИИ-агента
- `openai` — клиент OpenAI (GPT-4o mini для vision-верификации) и DeepSeek (навигация агента)
- `httpx` — HTTP-клиент для API-вызовов
- `python-dotenv` — загрузка переменных окружения
- `Pillow` — проверка и обработка изображений
- `playwright` — браузерный движок

## Примечания

- Для работы требуется графическое окружение (браузер открывается в GUI-режиме)
- Расход токенов GPT зависит от количества и размера изображений
- При повторном запуске с тем же запросом файлы не перезаписываются — каждый запуск создаёт новый набор
